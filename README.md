# pripara-virtual-camera

이미지 파일을 프리파라의 촬영·QR 스캔 입력으로 사용할 수 있게 하는 Windows x64 가상카메라 프로그램입니다. 상부 촬영용과 하부 QR용 카메라를 따로 제공하고, 게임이 출력한 티켓을 보관해 다시 표시할 수 있습니다.

현재 패키지 버전은 **1.1.2**이며, 앱 런타임은 **1.1.1**을 사용합니다. 1.1.2에서는 설치·패키지 구성을 정리했고 기존 앱과 네이티브 영상 처리 바이너리를 유지했습니다.

## 주요 기능

- 상부 촬영용·하부 QR용 이미지의 독립 선택과 송출.
- 이미지 파일 열기, 드래그 앤 드롭, `Ctrl+V` 붙여넣기.
- 전체 보기·화면 채우기, 회전, 좌우 반전, 해상도 선택.
- 최근 이미지와 번호 슬롯에 이미지 저장·불러오기.
- 게임에서 새로 저장한 BMP를 감시해 전체 티켓·마이티켓·우정티켓 PNG로 보관.
- 보관한 티켓을 선택해 QR 카메라에 표시.
- 게임 폴더의 카메라 설정을 맞추는 ‘게임 연결 설정’ 기능.
- 중복 실행 방지와 카메라별 송출 상태 표시.

| 용도 | 장치명 | 장치 ID |
| --- | --- | --- |
| 상부 촬영 | PriPara Upper Camera | `CAFE:0001` |
| 하부 QR 스캔 | PriPara QR Camera | `CAFE:0002` |

## 기본 사용

설치 프로그램으로 앱과 가상카메라 필터를 설치한 뒤 ‘프리파라 이미지 카메라’를 실행합니다. 카메라 등록과 송출 도우미에는 관리자 권한이 필요하며, 이미지 조작 화면은 일반 권한으로 동작합니다. 완성된 앱을 사용하는 PC에는 Python을 별도로 설치할 필요가 없습니다.

상부·하부 탭에서 이미지를 선택하고 카메라를 시작합니다. 게임과 QRReader의 설정이 필요하면 ‘게임 연결 설정’에서 게임 폴더를 지정합니다. 이 기능은 게임·QRReader의 카메라 설정 파일을 수정하며, 게임 실행 파일 패치를 대신하지 않습니다.

마이티켓·우정티켓 탭은 게임이 저장한 BMP를 읽습니다. 원본 BMP를 덮어쓰지 않고 별도 PNG로 보관하며, 기존 보관 파일과 중복되지 않게 이름을 정합니다. 티켓 자동 분할은 현재 지원하는 출력 레이아웃을 기준으로 하므로 다른 크기나 배치의 티켓은 별도 확인이 필요합니다.

앱 설치 위치는 `%LOCALAPPDATA%\PriParaImageCamera`, 필터 설치 위치는 `%ProgramFiles%\PriParaImageCameraDriver`입니다. 앱은 폴더형 구성으로 동작하므로 `PriParaImageCamera.exe`와 함께 제공되는 `_internal` 폴더를 유지해야 합니다.

## 구현 구조

```text
이미지·티켓 선택 화면
  → 로컬 IPC로 RGB 프레임 전달
  → 관리자 권한 송출 도우미
  → 네이티브 프레임 송출 DLL
  → 상부/하부 DirectShow 가상카메라
  → 게임 또는 QRReader
```

| 위치 | 담당 기능 |
| --- | --- |
| `app/app.py` | 이미지 라이브러리·미리보기·변환 |
| `app/app_dual.py` | 두 카메라와 티켓 탭을 묶는 PySide6 화면 |
| `app/camera_broker.py`, `app/ipc_files.py` | UI와 송출 도우미 사이의 로컬 파일 IPC |
| `app/camera_output.py` | 네이티브 송출 DLL의 C API 연결 |
| `app/ticket_capture.py`, `app/ticket_widgets.py` | BMP 감시·PNG 보관·티켓 갤러리 |
| `native/sender/` | WinAPI로 구현한 RGB 프레임 송출 |
| `native/upper/`, `native/qr/` | 상부·QR용 DirectShow 필터 |
| `installer/` | 앱 설치·필터 등록·게임 연결 설정·제거 |

이미지 처리는 Pillow·NumPy, 화면은 PySide6를 사용합니다. UI가 만든 RGB 프레임을 로컬 IPC로 송출 도우미에 전달하고, 네이티브 DLL이 공유 메모리 프로토콜을 통해 필터로 보냅니다. 송출 도우미는 프레임을 30fps 주기로 전달하며, QR 필터는 게임 입력에 맞춘 640×480 YUY2 형식을 제공합니다. 현재 송출 경로는 `pyvirtualcam`에 의존하지 않습니다.

BMP 수집기는 파일의 크기·시간과 이미지 읽기 상태가 안정된 뒤 저장합니다. 저장 이력은 로컬 SQLite에 기록하여 같은 출력의 중복 수집을 줄이고, 전체 티켓과 분할된 두 티켓을 함께 관리합니다. 이미지 라이브러리·슬롯·티켓은 사용자 PC에 보관합니다.

## 지원 범위

- Windows 10/11 x64용이며, 32비트 게임과의 연결을 위한 32/64비트 필터 구성을 사용합니다.
- 게임과 QRReader 자체는 포함하지 않습니다. QR 내용 생성·변환과 게임 패치는 별도 도구의 역할입니다.
- 테스트는 이미지 처리·IPC·송출 API·필터 형식 등의 범위를 확인합니다. 모든 PC의 설치·장치 등록·실제 게임 연결 성공을 확인한 것은 아닙니다.

프로젝트 전체 라이선스는 아직 지정하지 않았습니다. 포함된 Qt/PySide와 네이티브 구성요소의 저작권·라이선스 안내는 [구성요소 안내](THIRD_PARTY_NOTICES.md)를 확인하세요.
