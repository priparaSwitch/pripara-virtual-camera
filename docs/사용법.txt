프리파라 이미지 카메라 1.1.2

64비트 Windows 10/11용 설치 패키지입니다.
PriParaImageCamera_Setup_1.1.2.exe를 실행하고 설치를 누릅니다.
드라이버 등록 시 관리자 권한을 요청합니다. Python이나 OBS는 별도 설치하지 않습니다.
기존 이미지 카메라·QRReader·게임을 종료한 상태에서 설치합니다.

앱: 현재 사용자의 LocalAppData\PriParaImageCamera
드라이버: Program Files\PriParaImageCameraDriver
바탕화면과 시작 메뉴에서 '프리파라 이미지 카메라'를 실행합니다.
앱 화면은 일반 권한이며 송출 도우미는 관리자 권한으로 실행됩니다.

상부: PriPara Upper Camera / VID CAFE / PID 0001
하부: PriPara QR Camera / VID CAFE / PID 0002 / 640×480 YUY2
상부·하부에 서로 다른 이미지를 열거나 붙여넣고 각각 송출합니다.
가상카메라는 DirectShow 장치이며 물리 USB 장치를 만드는 방식은 아닙니다.
최근 이미지·슬롯과 마이티켓·우정티켓 보관 기능을 유지합니다.

게임 연결 설정 버튼에서 Prineo.exe가 있는 game 폴더를 지정합니다.
게임과 QRReader의 카메라 설정만 변경하며 게임 EXE는 수정하지 않습니다.
변경 전 설정을 게임 폴더에 보존합니다. 게임과 QRReader 자체는 제공하지 않습니다.
게임과 QRReader는 같은 권한으로 실행합니다.

앱 EXE만 단독으로 복사하면 실행에 필요한 라이브러리가 빠집니다.
Complete ZIP의 App 폴더는 _internal 폴더와 함께 유지해야 합니다.
일반 사용자에게는 완전한 설치 프로그램인 Setup EXE를 권장합니다.
Windows의 설치된 앱에서 제거할 수 있으며 보관 이미지는 유지합니다.

Source ZIP은 앱·필터·송출 모듈·설치 도구를 다시 빌드할 소스입니다.
QtSources ZIP은 대응하는 Qt/PySide 원소스이며 일반 실행용 파일은 아닙니다.
배포자는 QtSources·Source·SHA256SUMS와 라이선스 안내를 함께 제공합니다.
자세한 출처와 라이브러리 교체는 docs/DEPENDENCY_SOURCES.md를 참고합니다.

이번 버전은 공개 배포용으로 독립 송출 모듈과 최신 티켓 기능을 통합했습니다.
분리된 시험 채널·원수신 형식·필터 인터페이스·이미지/티켓/IPC를 검사했습니다.
실제 사용자 PC에서의 새 설치·장치 등록·게임 연결 성공은 아직 확인하지 않았습니다.
